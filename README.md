# Portfolio BTS SIO - David Musangu Tshibangu

Portfolio en une seule page pour le BTS SIO option SISR (UTEC de Melun).

Le site est composé de :

- `index.html` : la page du portfolio. Tout le contenu se modifie dans le bloc `PORTFOLIO` en haut du fichier.
- `cv.pdf` : le CV téléchargeable depuis la section « CV et contact ».
- `Start_Slide.pdf` : le diaporama du projet « Advanced Rescue Robot » (à ajouter dans le dépôt).
